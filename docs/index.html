Start here

A few clicks to get set up.

On a Mac

  1. Download the version for your Mac and open the .dmg file.
  2. Drag Second Pass into Applications.
  3. Open Second Pass from Applications.
If macOS blocks the first launch

After trying to open the app, go to System Settings > Privacy & Security and choose Open Anyway for Second Pass. Confirm Open. If asked, allow access to the document you want to edit.

This release has not been notarized by Apple. Use the exception for this app only. Apple's instructions.

On Windows

  1. Download and open the Setup.exe installer.
  2. Wait for the installation to finish. It installs for your Windows account.
  3. Open Second Pass from the Start menu.
If Windows shows a security prompt

If Microsoft Defender SmartScreen says the app is unrecognized, choose More info > Run anyway after confirming the download came from this GitHub repository.

If your company blocks installation, ask IT to approve it. The Windows download is an x64 build; a native ARM installer is not included.

Try it with the demo page.

Save the HTML to Documents, then open it in Second Pass. Edit the headline, replace the illustration, and save with Cmd+S on Mac or Ctrl+S on Windows. No account needed.

Work beside Codex

Connect your task.
Keep editing.

Codex is included. You don't need Node.js or a command-line setup.

An account with Codex access is needed for the connection. Local HTML editing works on its own.

  1. Create an HTML page in Codex on this computer.
  2. Copy the task link, paste it into Second Pass, and select Connect.
  3. If sign-in opens in your browser, sign in with your own account. Return to Second Pass and select Connect again.
  4. Save direct edits before asking Codex to change the page. Larger changes will refresh in Second Pass when Codex saves them.
A task link does not copy files between computers. To share a page with a teammate, send the HTML and its image folder. They can open it directly or connect their own local Codex task.
