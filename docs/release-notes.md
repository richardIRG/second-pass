Second Pass is ready for a first team rollout on Mac and Windows.

**[Download and setup guide](https://richardirg.github.io/second-pass/)**

## Choose your download

- Mac with an M-series chip: **Second-Pass-Mac-Apple-Silicon.dmg**
- Mac with an Intel processor: **Second-Pass-Mac-Intel.dmg**
- Windows with an Intel or AMD processor: **Second-Pass-Windows-x64-Setup.exe**

Open the Mac disk image and drag Second Pass to Applications, or run the Windows installer. Codex is bundled. No Node.js or command-line installation is needed. HTML editing works without an account.

## In this release

Direct text editing, image replacement, undo and redo, responsive previews, source-preserving saves, automatic backups, and a Codex conversation beside the page. New users sign in through their browser when they connect a Codex task.

## First launch

These initial installers do not have a verified publisher signature.

- Mac: If blocked, use **System Settings > Privacy & Security > Open Anyway** for Second Pass.
- Windows: If SmartScreen appears, use **More info > Run anyway** after confirming the download is from this repository.
- Company-managed computers may need IT approval.

Task connections require the task and its files on the same computer and your own Codex-enabled account. Native Windows ARM builds and automatic updates are not included. SHA-256 checksum files are included.
